Mail Connector

Mail Connector 是一个邮箱接入服务。用户授权后，AI 助手可以读取用户本人的 Gmail 或 Outlook 收件箱，用于查询邮件和提醒新邮件。

Mail Connector lets an AI assistant read a user's own Gmail or Outlook inbox after the user grants permission, so the assistant can search mail and notify the user about new messages.
